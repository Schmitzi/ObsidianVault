# Roadmap

Here is where I will begin to transcribe all of the ideas that were had during our initial brainstorming session.

## MVP

For a minimum viable product, we are going to demonstrate Symbiotes ability to:

- *Show map of the festival area*:: Having an offline map of the festival grounds is basic.
    - Also being able to save your tents location as a `pin`is important.
- *Feedback*: being able for the user to be able to send an internal message/email to us.
- *Accounts*: due to the nature of the environment, anonymous accounts will be needed for each user.

## Want to Have

Not nescessary at first, but probaly will make it to MVP.

- *Groups*: the ability to establish a group with those who you are spending your time with.
    - Additionally, the ability to designate a leader who can manage the group, however this is not required.
    - Location sharing by being able to share or request location inside the group.
- *Lifelines*: added points ofminterest on the map for things such as:
    - Water
    - Toilets
    - First aid
    - PsyHelp
    - Awareness
    - Tech support
- *Stalls*: a searchable list/map overlay to show what is available to purchase (e.g. merch, food, etc)
    - Includes information on dietary requirements and prices (specify that it's subject to change)
    - This will tie into to future cashless system
- *Lost & Founds*: if the festival provides such a thing, giving info on where to find this.

Also, being able to "toggle" these when they become unavailable, out of order, etc.

## Accessibility

This will include, but is not limited to:

- *Localization*: the ability to pick a desired language.
- *Ease of access*: features to help support those with a disability (e.g. blind assistance).

## Developer Tools

Some extra things that would help to improve the app, some may become user features.

- *Heatmap*: being able to map the movement of people to see where/if the network needs support or is not working as intended.

## Cashless System

This will be the biggest challenge as it requires abiding by several laws and protocols. Essentially, each user will
be provided with armband (or phone can be used through NFC) which allows them to be able enjoy the festival without the use of cash.
This allows the user to connect more with their environment.

Top-ups will only be available through a vendor requiring little to no setup. No one has PayPal.

Each stall will be provided with terminal (for a small bond) that allows the user to pay directly(?).

## Connectivity through Mesh Network

To achieve a system that is both off grid and low power, a mesh network can be used to "hop" the messages across distances.
This allows festivals with poor cellphone coverage to stay connected and users to keep in contact even without a 5G/LTE signal.
