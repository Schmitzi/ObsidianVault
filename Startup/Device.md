# Device

The device at the core of this setup will be custom built running a stripped down x86 64-bit Linux Distro, most likely Arch.

At its heart will be a Latte Panda Mu attached to a carrier/breakout board. This will allow us to use the GPIO pins to attach expansions like a
satelite signal receiver aswell as giving us the ability to host the mesh network.

## Specs

- N100 4-core 3.4GHz  processor
- 8GB 4800MHz LPDDR5 RAM
- 64GB eMMC storage (expanable)
- Intel UHD Graphics
- 6-35W Power Consumption
